# 프로젝트 최종 점검 체크리스트

## 1. 요구사항
- [ ] 모든 기능 요구사항이 요구사항 정의서에 등록되어 있다.
- [ ] 모든 요구사항에 요구사항ID가 부여되어 있다.

## 2. 기능
- [ ] 회원가입 / 로그인 / 회원관리가 정상 동작한다.
- [ ] 게시판 목록(검색·페이징) / 상세 / 등록 / 수정 / 삭제가 정상 동작한다.
- [ ] 역할·권한 기반 접근제어가 정상 동작한다.

## 3. UI
- [ ] 모든 화면이 화면 목록/스토리보드와 일치한다.
- [ ] 오류 메시지가 사용자 친화적으로 표시된다.

## 4. 데이터
- [ ] ERD의 모든 테이블에 기본키/외래키가 올바르게 설정되어 있다.
- [ ] 정규화 원칙에 따라 데이터 중복이 최소화되어 있다.

## 5. 테스트
- [ ] 단위 테스트, 통합 테스트가 모두 통과한다.
- [ ] 경계값·예외 테스트가 포함되어 있다.

## 6. 보안
- [ ] SQL Injection, XSS, CSRF에 대한 방어 조치가 되어 있다.
- [ ] 접근제어가 모든 관리자 API에 적용되어 있다.
- [ ] 비밀번호가 해시로 저장된다.

## 7. 배포
- [ ] 빌드가 오류 없이 완료된다.
- [ ] 배포 후 헬스 체크가 정상이다.
- [ ] Git 저장소에 모든 변경 이력이 커밋되어 있다.
