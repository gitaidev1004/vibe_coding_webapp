# Wordpad Clone 프로젝트 안내

## 기술 스택
- React 18 + Vite 5 (JavaScript, JSX)
- 외부 UI 라이브러리는 사용하지 않는다.

## 자주 쓰는 명령
- 개발 서버 실행: npm run dev (http://localhost:3000)
- 배포용 빌드: npm run build

## 코딩 규칙
- 컴포넌트는 함수형 컴포넌트와 Hook만 사용한다.
- 파일 저장/열기 로직은 src/fileio.js 에 둔다.
- 새 패키지를 설치하기 전에 먼저 사용자에게 물어본다.
- 주석과 설명은 한국어로 작성한다.
