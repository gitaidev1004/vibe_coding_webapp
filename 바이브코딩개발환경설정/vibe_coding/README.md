# VS Code에서 Codex와 Claude Code 사용하기 - 교재 소스 코드

| 폴더 | 내용 |
|------|------|
| ch01/check_env.js | 실습 환경(Node.js) 점검 스크립트 |
| ch02/prompts/first_prompt.txt | Codex용 첫 프롬프트(영어) |

## 실행 방법
1. Node.js 18 이상 설치 (node -v 로 확인)
2. cd ch04/wordpad-clone
3. npm install
4. npm run dev   ->  http://localhost:3000
